個人資料保護、隱私權政策暨服務條款

最新版本修訂日期：2026 年 8 月 20 日

本頁目錄一、適用範圍二、蒐集與用途三、隱私承諾四、本機儲存五、第三方服務六、未成年人保護七、資料保留八、當事人權利九、條款修訂

我們採取資料最小化原則，不販售資料、不設置廣告追蹤器，公開成果僅呈現去識別化統計。

歡迎存取「新竹縣第四屆兒童及少年諮詢代表官方網站」（以下簡稱「本網站」）。本網站由新竹縣第四屆兒童及少年諮詢代表（以下簡稱「竹縣少代會」）負責維運管理，並受指導機關新竹縣政府社會處指導。

本網站主要用於辦理縣內不定期兒少權益專題調查。本政策說明我們如何蒐集、處理、利用與保護資料，以及您依法可行使的權利。

一、總則與政策適用範圍

本政策適用於您在本網站首頁、議題調查總覽及個別調查問卷所進行的瀏覽與填答行為；實際網址可能依 GitHub Pages 路由格式呈現。

二、個人資料蒐集類別與服務功能

服務功能蒐集項目主要用途
兒少專題議題調查題目回答內容；依問卷需要選填學校、年級或年齡區間產出去識別化統計，作為提案與倡議依據
填答歷程統計開始時間、送出時間、作答費時評估題目設計與辨識異常提交
管理後台認證授權管理員電子郵件Magic Link 免密碼登入及白名單驗證

三、我們的隱私承諾

  1. 不販售或出租資料：不將個人資料販售、出租或交換予商業廣告機構。
  2. 不設置廣告追蹤器：不安裝 Meta Pixel、Google Analytics 等跨站行為追蹤工具。
  3. 不公開原始個資：調查成果一律以去識別化圖表或統計公開。

四、Cookie 與本機儲存規範

一般訪客瀏覽與填答時不寫入任何行銷、追蹤或廣告用途 Cookie。僅於管理員登入時，使用瀏覽器儲存空間暫存必要的授權狀態。開發示範模式產生的測試資料僅暫存於目前分頁的工作階段，關閉分頁後即失效。

五、雲端基礎設施與第三方服務

GitHub Pages

提供 HTML、CSS、JavaScript 與公開圖片的靜態網站託管，並可能透過自訂網域 hcccr.bond 對外提供服務；GitHub Pages 不作為調查回答資料庫。GitHub 可能依其基礎設施政策處理必要的連線記錄。

Supabase

提供 PostgreSQL 資料庫、驗證與檔案儲存，並透過 Row Level Security 控管權限。

Resend

僅用於管理員 Magic Link、系統通知及經主動同意的調查通知。

QR Code 產生服務

僅於管理員主動產生調查固定網址 QR Code 時傳送該公開網址；不會傳送填答內容。

jsDelivr

用於載入 Supabase 官方瀏覽器套件、圖示、後台統計圖表與 Excel 工作簿產生程式。Excel 檔案僅在已授權管理員的瀏覽器中產生，不會將原始回應傳送至 jsDelivr；本網站亦不透過該服務進行廣告或跨站追蹤。

六、未成年人及兒童特別保護

多數調查提供匿名填寫，且不強制要求超出研究目的所需的資料。學校、年級等欄位將明確標示是否選填及統計用途。填答者應避免在自由文字欄位提供姓名、班級、電話等可直接識別個人的資訊。

七、資料保留期限與刪除

調查資料於本屆少代會任期及議題倡議必要期間內保存。管理團隊可刪除無效、測試或異常回應；授權管理員得因統計、倡議與內部稽核需要匯出 Excel，下載檔案須妥善保管，不得公開散布可識別個人或含原始自由填答內容的版本。您也可依法提出查詢、更正、停止利用或刪除要求。

八、個資當事人權利

依《個人資料保護法》第 3 條，您得請求查詢、閱覽、複製、更正、停止蒐集處理利用或刪除資料。如需行使權利，請透過網站公開聯繫管道提出申請，我們會在確認身分與回應識別資訊後辦理。

九、條款修訂與公告

本政策得因法令、少代會運作或技術變更修訂。修訂後版本將發布於本頁，重大異動另於首頁公告。
